How to read the Herdr sidebar

The sidebar is a live view of your Herdr server: every space, the agents and shells in it, and what each one is doing. Nothing runs inside VS Code. Agents and shells keep running in Herdr, and the terminal tabs VS Code opens are just windows onto them.

Bars (5h, 7d)
The share of your plan's 5-hour and weekly limits used, and when each window resets (↻). Blue below 60%, orange from 60%, red from 85%. reset means the window has started over since the agent last reported, so it's at 0%.
live / as of
live: fetched from the provider just now. as of …: when the agent last reported the numbers; they update while you use it.
Codex
Live: every 5 minutes the sidebar asks Codex itself (the same data as Codex's /usage, so it includes Codex use on other machines and in the IDE). Codex signs that request with its own login; Herdr never sees it. If Codex can't answer, the sidebar falls back to Codex's session logs, which are only as fresh as your last Codex prompt.
Claude Code
The bars match Claude's own /usage ("Current session" and "Current week (all models)"). Per-model weekly limits (such as "Current week (Fable)") aren't shared outside Claude Code, so they're not shown. This session counts the tokens Claude Code used on this machine in the current 5-hour session (input, output and cache writes; hover for cache reads). Without plan limits the session window is estimated from your first message (5-hour block (est.)). Claude Code shares its plan-limit percentages only with a status line, so the bars appear after you click Show plan limits…: Herdr adds a small status line to ~/.claude/settings.json (backed up first; it shows "5h 42% · 7d 18%" under the Claude prompt and hides some of Claude Code's footer hints). It works for claude.ai Pro and Max plans; numbers appear after the next Claude reply. To undo, remove statusLine from that file. If you already have a status line, Herdr leaves it alone and shows how to add the capture to it.
Kiro
Credits used today and this month, from Kiro's session files (Kiro CLI on this machine). Kiro doesn't share your plan's allowance with other tools, so click Set monthly credits… once and enter the number from Kiro's /usage (setting herdr.kiroMonthlyCredits); the mo bar then shows how much of it you've used, renewing on the 1st.

Create, rename and close

New space (next to "Spaces", or in the view's title bar)
Pick Choose a folder…, or New git worktree of an existing space: a separate checkout on a new branch, so an agent can work without touching your current branch (Herdr puts it in ~/.herdr/worktrees/<repo>/<branch>). Then name it and choose what to start. The window switches to the new space.
New tab (bottom of a space card, or right-click a space)
Choose Shell, Shell with a name… or an agent. The agents listed first come from the herdr.agents setting; More agents… lists every agent Herdr can start. The tab opens right away; an agent starts in it in the background (a notification shows progress).
The button of VS Code's terminal
In the hub window, a plain + creates a Herdr shell tab in the current space: the space of the terminal you're in, else the space mounted in the window, else the one focused in Herdr. Its dropdown has Herdr: Claude, Codex, Kiro, Cursor and Other Agent…, plus your normal local shells. In other windows the Herdr entries are in the dropdown only. If Herdr isn't reachable, + opens a local shell.
Rename… (right-click)
Spaces take any name. Shells too (empty = use the tab name). Agent names are identifiers in Herdr: lowercase letters, digits, - and _ (for example reviewer). The open VS Code tab is renamed as well.
Close in Herdr… (right-click)
Stops the shell or agent, or a whole space, after asking. (Closing the VS Code tab only detaches.) For a worktree space you can also delete its worktree folder; Herdr refuses if it has uncommitted changes and asks before forcing it.

Herdr can report an agent as started even when that agent isn't installed. If a new agent tab shows "command not found", install the agent's CLI first.

Terminal tabs

  • Click any agent or shell row to open it in a VS Code terminal tab. The tab has the same name as the row and the agent's logo as its icon. Clicking again brings the existing tab forward.
  • Agents open with takeover: your keystrokes go to the agent from this tab.
  • Closing a tab only detaches. The agent or shell keeps running in Herdr. Inside the tab, ctrl+b then q also detaches.
  • In the hub window, tabs show only their name. Elsewhere VS Code adds the folder name after it; to hide that in every window, set terminal.integrated.tabs.description to ${task} in your user settings.
  • Switching spaces closes the previous space's tabs (setting herdr.closeTerminalsOnSwitch). Tabs open in the editor area or the bottom panel (herdr.terminalLocation).

Status bar, badge and alerts

  • Status bar (bottom left): agent count, then working , blocked and done counts. It turns yellow when something is blocked. Click it to jump to the agent that needs you. means Herdr isn't reachable; click to retry.
  • Badge on the sidebar icon: how many agents are blocked or done.
  • Notifications when an agent becomes blocked or done, with Attach and (when done) Review changes buttons.

Follow mode and the hub window

Follow mode ( in the title bar): when you switch spaces in Herdr itself, this window switches too. To avoid hijacking unrelated windows it only acts in the hub window, or in a window where you've already switched a space from the sidebar.

The hub window ( menu → Set up Herdr Hub Window) is a dedicated VS Code window for Herdr. Its first folder never changes, so switching spaces never restarts your extensions.

Troubleshooting

"Herdr isn't reachable"
Start the server by running herdr in any terminal, or use Open Herdr TUI. If you use a named session or a custom socket, set herdr.socketPath.
Clicking a space says "open a folder first"
Spaces are mounted next to the folder the window already has. Open any folder, or set up the hub window.
A terminal tab won't open
VS Code may not find the herdr binary when launched from the Dock. Set herdr.binaryPath.
Something looks wrong
Right-click it → Show Raw Herdr Record, or → Show Raw Session Snapshot. The Herdr Bridge output panel logs connections and follow-mode switches.
