# Start Herdr

Herdr Hub is a window onto your [Herdr](https://herdr.dev) server: your agents and shells keep running in Herdr, not in the editor.

- Already use Herdr in a terminal? Nothing to do: the sidebar connects to it.
- Not running? **Start Herdr** runs the server in the background. It keeps running after you close the editor.
- Not installed? See [herdr.dev](https://herdr.dev/docs/install/).
