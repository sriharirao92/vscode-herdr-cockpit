# Find the sidebar

Herdr Cockpit lives in the activity bar. The Cockpit window opens it the first time.

- **Cursor** shows the activity bar as a row of icons across the top of the sidebar. Icons that don't fit sit behind the **⌄** arrow at the end of the row.
- You can drag the Herdr Cockpit icon to the other side of the window, next to the editor.
- The Command Palette always works: **Herdr Cockpit: Focus on Spaces & Agents View**.
