# Find the sidebar

Herdr Hub lives in the activity bar. The hub window opens it the first time.

- **Cursor** shows the activity bar as a row of icons across the top of the sidebar. Icons that don't fit sit behind the **⌄** arrow at the end of the row.
- You can drag the Herdr Hub icon to the other side of the window, next to the editor.
- The Command Palette always works: **Herdr Hub: Focus on Spaces & Agents View**.
