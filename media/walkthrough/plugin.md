# The Herdr plugin

The companion Herdr plugin works from Herdr's terminal side:

- **Open in editor**: jump from the space or pane you're on in Herdr to the same space in this editor.
- **Open file**: select `src/app.ts:42` in any pane and open it at that line.
- **Review changes** of a pane's repository in the editor.
- **Status**: is the hub window connected, and what's attached.

Install it with `herdr plugin install sriharirao92/herdr-hub/plugin`. Herdr shows what the plugin will run and asks before installing.
