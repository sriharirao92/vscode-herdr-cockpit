# The hub window

The hub window is a dedicated window for Herdr. Its first folder (`~/.herdr-hub`) never changes, so switching spaces never restarts your extensions. Each space's folder is mounted next to it.

A window opened without a folder (a new window, or the editor's first launch) offers **Open Herdr Hub**, which turns that window into the hub.

In the hub window:
- switching spaces in Herdr's terminal switches the window too (follow mode);
- the terminal **+** creates Herdr tabs;
- terminal tabs show just their name.
