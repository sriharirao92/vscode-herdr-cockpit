# The Cockpit window

The Cockpit window is a dedicated window for Herdr. Its first folder (`~/.herdr-cockpit`) never changes, so switching spaces never restarts your extensions. Each space's folder is mounted next to it.

A window opened without a folder (a new window, or the editor's first launch) offers **Open Herdr Cockpit**, which turns that window into the hub.

In the Cockpit window:
- switching spaces in Herdr's terminal switches the window too (follow mode);
- the terminal **+** creates Herdr tabs;
- terminal tabs show just their name.
